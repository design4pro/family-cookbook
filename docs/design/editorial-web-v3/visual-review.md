# Visual review

Date: 2026-10-15. Scope: three raster studies, not a running interface. This is review evidence, not developer approval.

Subsequent outcome: the developer rejected these studies as amateurish and supplied Smakopas as a concrete reference. The positive observations below remain the historical internal assessment; they did not establish an acceptable visual direction. See the [reference analysis and process correction](../smakopas-reference-analysis.md).

## First batched inspection

The lead inspected all generated frames. An independent reviewer also opened all three files, compared them with v2 and the reference analysis, and found a more consistent typographic hierarchy, palette and reading structure. Text-only entries no longer looked like missing photographs. Recipe actions appeared before the reading columns; quantities and names were aligned clearly.

Three material issues were identified:

1. The Apple cake thumbnail introduced unprovided source details.
2. The narrow-screen label “Shopping list” looked like navigation rather than an addition action.
3. The narrow source thumbnail changed the paper's proportions and handwriting layout relative to desktop.

## Single correction batch and confirmation

- Replaced the Apple cake thumbnail with a text-only entry. No invented ingredient quantities, time or temperature remain in that entry.
- Changed the narrow action to “Add ingredients”. Both web addition actions must open a review-and-confirm step before changing the shared shopping list. The static studies do not depict that subsequent flow.
- Used the index as the source-image reference for both recipe revisions and restored a portrait sheet in the narrow view. Final visual inspection confirmed portrait proportions and the same factual content. Generated handwriting remains an illustrative reconstruction, not a byte-identical shared asset. Exact reuse must be established with the original image in an eventual implementation; these rasters cannot prove source immutability.

The lead inspected the final three outputs together. The retained facts are flour 2½ cups, two eggs, milk 250 ml, salt without an amount, and the two supplied method steps. Servings, time and temperature remain unspecified. No dish photography or new factual family story was introduced.

Large headings are intentional in this proposal. The desktop recipe's controls, ingredients and method remain visible in one frame. Narrow web is a scrolling full-page study, with source access after the recipe. Real Polish content, dynamic text and longer recipes have not been rendered yet.

## Process lesson

After a rejected visual direction, inspect named references and diagnose composition before expanding the same language across more screens. Evaluate text-only content early. Keep one authoritative source asset for subsequent production work; repeated generative renderings are unsuitable evidence that an original remained unchanged. This packet records that limitation rather than claiming a fidelity pass.

Final PNG prompt metadata and file/link integrity are checked separately. No application tests were run because no application files changed. Accessibility, responsiveness, native Liquid Glass behavior and readiness gates are not established by this review.
